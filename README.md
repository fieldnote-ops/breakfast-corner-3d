# 窗边，早餐。

一个有微风、树叶与斑驳光影的交互式三维早餐角落。使用 Blender 创建实体模型，通过 Three.js 展示。

可以旋转、缩放和平移，切换参考图视角、坐在桌前和空间全貌。晨光和风力均可调节，也可以暂停风动或生成留影。

## 运行

这是纯静态网站，GitHub Pages 从 main 分支的根目录发布。网页依赖与 GLB 模型均随仓库提供。
